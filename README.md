# ✝ 교회 PPT 자동화 도구

## 실행 모드

| 모드 | 실행 | 비밀번호 |
|---|---|---|
| 로컬 | `run.bat` / `python app.py` | 없음 |
| 서버 | Docker (`Dockerfile`) | `APP_PASSWORD` |

서버에는 아무것도 저장하지 않습니다. 찬송가 폴더, 템플릿 파일, 설정(찬송가 슬롯·슬라이드 번호 기본값)은 모두 각자 브라우저에 있습니다. 생성할 때 고른 곡과 템플릿만 요청에 실어 보내고, 임시파일은 요청이 끝나면 삭제됩니다. 설정은 브라우저(localStorage)에 저장됩니다. 처음 접속한 브라우저는 배포본의 `static/default-config.json`(찬송가 슬롯·슬라이드 번호 기본값)으로 시작하고, 이후 각자 바꾼 값은 그 브라우저에만 남습니다. 모두의 기본값을 바꾸려면 이 파일을 수정해 배포하세요.

### 환경변수

| 변수 | 설명 |
|---|---|
| `APP_PASSWORD` | 설정하면 공유 비밀번호 로그인이 켜집니다 |
| `SECRET_KEY` | 세션 쿠키 서명 키 (`APP_PASSWORD` 사용 시 필수) |

`GET /api/health`는 로그인 없이 호출할 수 있습니다.

## 사용 방법

### ⚙️ 최초 설정 (설정 탭)
1. **찬송가 폴더**: 찬송가 PPTX 파일들이 있는 폴더 선택
2. **기본 템플릿**: 매주 사용하는 템플릿 파일 선택
3. **찬송가 슬롯**: 매주 고정적으로 찬송가를 넣는 위치 등록
   - 예: "1부찬양" → 슬라이드 3 이후, "2부찬양" → 슬라이드 8 이후
4. **설정 저장** 클릭

---

### 📋 주보 생성 (기능 1)

1. 템플릿 파일 경로 확인
2. 각 슬롯에 찬송가 번호 입력 (예: 23)
   - 자동으로 파일명에서 제목을 검색해 표시
3. 이번 주 사용 안 하는 슬롯은 "스킵" 체크
4. **PPT 생성하기** 클릭 → 파일 다운로드

---

### 🎵 성가대 가사 (기능 2)

1. 템플릿 파일 경로 입력 후 **슬라이드 보기**
2. 슬라이드 목록에서 클릭해서 선택:
   - 먼저 **제목 슬라이드** 클릭
   - 그 다음 **가사 템플릿 슬라이드** 클릭
3. 가사 입력 (빈 줄로 단락 구분)
4. **미리보기**로 슬라이드 분할 확인
5. **성가대 PPT 생성** 클릭
